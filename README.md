# Coffee Chain Database (MySQL)

Relational database for a coffee-chain ordering & membership system,
modeled on Starbucks Thailand.

## Background
Originally a 5-person group project for ITCS216 Fundamentals of Database
Systems (Mahidol University ICT, 1/2025). This version was redesigned and
extended by Sirirampa Luangphiphatsorn.

Original team: Chanachon Ruanpheng, Yanapat Sittirat,
Chanapron Sumkhemthong, Ratchanon Srithongkul

*Educational project, not affiliated with Starbucks.*
